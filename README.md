# تصريح دخول الصف — تطبيق ويب تقدّمي (PWA)

تطبيق مدرسي لإصدار تصاريح دخول الحصة للطلاب وإرسالها لمعلمي الحصص عبر واتساب نصًا أو صورة.
يعمل بالكامل داخل جهاز المستخدم: لا خادم، ولا حساب، ولا إنترنت بعد أول فتح.

## التشغيل محليًا
عامل الخدمة (Service Worker) لا يعمل بفتح الملف مباشرة بنظام `file://`، لذلك شغّل خادمًا بسيطًا:

```bash
cd class-entry-permit-pwa
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```
أو: `npx serve .`

## النشر
ارفع محتويات المجلد كما هي على أي استضافة ملفات ثابتة تدعم HTTPS:
GitHub Pages أو Netlify أو Vercel أو Cloudflare Pages أو استضافة المدرسة.
شرط التثبيت والعمل دون إنترنت: أن يكون الموقع على **HTTPS** (أو localhost).

## التثبيت على الجهاز
- **أندرويد / كروم:** افتح الرابط ← «تثبيت التطبيق» من داخل صفحة الإعدادات في التطبيق، أو من قائمة المتصفح «إضافة إلى الشاشة الرئيسية».
- **آيفون / آيباد:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## بنية المشروع
```
index.html               الواجهة
css/styles.css           التنسيقات
css/fonts.css            تعريفات خط Cairo المحلية
fonts/                   ملفات خط Cairo (woff2) — عربي 400/600/700/900 ولاتيني 400/600/700
js/app.js                منطق التطبيق كاملًا
vendor/                  مكتبتا SheetJS (إكسل) و html2canvas (تحويل البطاقة لصورة) — محليًا للعمل دون إنترنت
icons/                   أيقونات التطبيق PNG و SVG (بينها maskable لأندرويد)
manifest.webmanifest     بيانات التطبيق للتثبيت
sw.js                    عامل الخدمة والتخزين المؤقت
```

## البيانات
تُحفظ في **IndexedDB** داخل المتصفح (قاعدة `ClassPermitDB`)، وتبقى بعد إغلاق التطبيق،
ولا تُحذف إلا من زر «حذف كل البيانات» في الإعدادات. ويُنصح بتصدير نسخة احتياطية (ملف JSON) بين حين وآخر.

## تحديث نسخة التطبيق
بعد أي تعديل على الملفات، غيّر رقم الإصدار في أول سطر من `sw.js`:
```js
const CACHE = 'class-permit-v2';
```
ليتم تحميل النسخة الجديدة لدى المستخدمين بدل النسخة المخزّنة.
