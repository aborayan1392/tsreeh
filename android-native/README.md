# تصريح دخول الصف — Android Kotlin

تطبيق أندرويد أصلي كامل بواجهة عربية RTL لإصدار تصاريح دخول الحصة للطلاب وإرسالها للمعلمين نصًا أو بطاقة صورة.

## الوظائف

- إصدار تصريح لطالب واحد أو عدة طلاب ولمعلم واحد أو عدة معلمين.
- خمسة أساليب مخاطبة مطابقة للنسخة الأصلية، وعشرة أسباب جاهزة مع سبب مخصص.
- التاريخ الهجري والميلادي، الوقت، الصف، الحصة، المادة، والرقم التسلسلي.
- بطاقة تصريح رسمية عالية الدقة قابلة للحفظ والمشاركة.
- إرسال نص أو صورة إلى واتساب، ونسخ النص للحافظة.
- إدارة الطلاب: إضافة جماعية، بحث، تعديل، حذف، عدادات التصاريح، استيراد وتصدير Excel.
- إدارة المعلمين: الاسم ورقم الجوال، بحث، تعديل، حذف، استيراد وتصدير Excel.
- سجل كامل للتصاريح مع إعادة الفتح والمشاركة والحذف والتصدير.
- إعدادات المدرسة والمصدر والمدير والجهة التعليمية ومفتاح الدولة.
- نسخة احتياطية JSON واستعادة كاملة ومسح البيانات.
- قاعدة بيانات SQLite محلية، والعمل دون اتصال بالإنترنت.
- تصميم متجاوب للجوال والتابلت، وخط Cairo مضمن داخل المشروع.
- أيقونة أصلية معبرة عن دخول الصف والتصريح المعتمد.

## البناء

يفتح المشروع مباشرة في Android Studio، أو يُبنى بالأمر:

```bash
gradle :app:assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`

- الحد الأدنى: Android 8.0 (API 26)
- الهدف: Android 15 (API 35)
- اللغة: Kotlin + Jetpack Compose
- التخزين: SQLite
